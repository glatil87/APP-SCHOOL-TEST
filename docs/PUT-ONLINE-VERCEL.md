# Putting the app online with Vercel

Vercel is a free hosting service made by the same company as the web toolkit
this app uses. You sign in with your GitHub account — no new password and no
card needed.

1. Go to **vercel.com** and click **Sign Up**.
2. Choose **Hobby** (the free plan), type your name, and click **Continue**.
3. Click **Continue with GitHub** and sign in with the same GitHub account that
   holds APP-SCHOOL-TEST. Click **Authorize Vercel** if asked.
4. You'll see **Import Git Repository**. If APP-SCHOOL-TEST isn't listed,
   click **Adjust GitHub App Permissions**, choose **Only select
   repositories**, pick **APP-SCHOOL-TEST**, and click **Save**.
5. Click **Import** next to **APP-SCHOOL-TEST**.
6. Don't change any settings. Click **Deploy**.
7. Wait about 2 minutes for the confetti 🎉, then click **Continue to
   Dashboard**. The web address is shown under **Domains** (it ends in
   `vercel.app`). Open it on your phone.

Tip: on iPhone, open the address in Safari, tap **Share**, then **Add to Home
Screen**, and it will open like an app.

After this, every time new work is saved, Vercel updates the app
automatically, at the same address.
